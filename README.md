Meu Gestor Financeiro (Projeto de Faculdade)

Este é um projeto de aplicação web simples, criado com React (via Vite), para um trabalho de faculdade. O objetivo é demonstrar conceitos modernos de desenvolvimento web em uma aplicação de gestão de finanças pessoais.

Conceitos Implementados

Este projeto atende aos requisitos do trabalho ao implementar:

Gerenciamento de Estado: Utiliza a Context API e o hook useReducer do React para criar um estado global e controlar a lista de transações (adicionar/remover).

PWA (Progressive Web App): Inclui um manifest.json e um sw.js (Service Worker) para permitir que a aplicação seja "instalável" e funcione offline.

Como Executar o Projeto

Para rodar este projeto localmente, siga os passos:

Abra um terminal na pasta raiz do projeto.

Instale todas as dependências necessárias:

npm install

Inicie o servidor de desenvolvimento:

npm run dev

Abra o endereço http://localhost:5173 (ou o que for indicado no seu terminal) no seu navegador.
